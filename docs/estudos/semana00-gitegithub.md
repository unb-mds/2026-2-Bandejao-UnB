## Resumo

Git é uma ferramenta de controle de versão — ele acompanha e registra as mudanças feitas em um projeto ao longo do tempo, funcionando como um histórico que permite consultar e voltar a versões anteriores das alterações. Já o GitHub é uma plataforma online para armazenar projetos que usam Git, permitindo trabalho colaborativo: várias pessoas podem compartilhar o mesmo código e trabalhar nele em equipe.

## Aplicação no projeto

O GitHub é a plataforma usada pelo grupo para compartilhar o projeto do site do RU, dando acesso ao código para toda a equipe. Isso garante mais controle sobre o código em grupo, mantém o histórico de versões do site e facilita a organização de quem trabalha em qual parte do projeto.

## Principais conceitos / como usar

**Conceitos fundamentais:**
- **Repositório:** onde o Git armazena os arquivos do projeto e o histórico de alterações.
- **Branch:** linha independente de desenvolvimento, que permite fazer alterações sem afetar diretamente a branch principal.
- **Commit:** registro de uma alteração feita no projeto, acompanhado de uma mensagem descrevendo o que foi mudado.
- **Staging Area:** área intermediária onde ficam as alterações selecionadas para entrar no próximo commit.
- **Pull Request:** solicitação para que alterações feitas em uma branch sejam revisadas antes de serem integradas.

**Comandos importantes:**
- `git init` — cria um novo repositório.
- `git clone` — copia um repositório para o computador.
- `git status` — mostra o estado atual do repositório.
- `git add` — adiciona alterações à Staging Area.
- `git commit` — registra as alterações no histórico.
- `git push` — envia commits locais para o repositório remoto.
- `git pull` — busca e integra alterações do repositório remoto.
- `git fetch` — busca informações do repositório sem integrar as alterações à branch atual.
- `git branch` — lista ou cria branches.
- `git switch` — muda de branch.
- `git merge` — combina alterações de uma branch com outra.
- `git log` — mostra o histórico de commits.
