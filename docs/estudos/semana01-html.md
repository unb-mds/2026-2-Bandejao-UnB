## Resumo

HTML (HyperText Markup Language) é a linguagem de marcação usada para criar e organizar a estrutura de páginas da web. É por meio dele que se definem os elementos que aparecem em uma página — títulos, textos, imagens, links, listas, tabelas, botões e formulários.

Ele funciona através de tags, que indicam ao navegador o que cada parte do conteúdo representa (por exemplo, uma tag para indicar um título e outra para um parágrafo).

O HTML, sozinho, não é responsável pela aparência da página nem por comportamentos complexos. Ele trabalha em conjunto com:
- **CSS**, que cuida da aparência e do estilo da página;
- **JavaScript**, que adiciona interatividade e funcionalidades.

## Aplicação no projeto

O HTML será utilizado para estruturar as telas que serão desenvolvidas ao longo do projeto, funcionando como base geral para a construção das páginas do sistema. Ele define onde cada informação e elemento vai ficar, podendo ser usado para organizar as informações de cada funcionalidade — como fila, cardápio e também na parte de infraestrutura.

## Principais conceitos / como usar

**Estrutura básica de uma página**

Um documento HTML normalmente começa com `<!DOCTYPE html>` (que informa ao navegador a versão do HTML usada) e é dividido em três partes principais:
- `<html>` — elemento raiz que envolve todo o conteúdo;
- `<head>` — contém metadados da página (título, links para CSS, etc.), não visíveis diretamente;
- `<body>` — contém o conteúdo visível da página.

**Tags comuns**

| Tag | Função |
|-----|--------|
| `<h1>` | Título |
| `<p>` | Parágrafo |
| `<a>` | Link |
| `<img>` | Imagem |
| `<ul>` / `<li>` | Lista (não ordenada) e seus itens |
| `<div>` / `<section>` | Organização/agrupamento de conteúdo |

**Atributos**

Atributos adicionam informações extras às tags. Exemplo com a tag de imagem:
- `src` — indica o caminho/local da imagem;
- `alt` — descrição textual da imagem (importante para acessibilidade).
